Privacy Policy

Effective: October 18, 2026

WorthKnowing Revenue Pilot is a private-owner automation used only to manage the owner's own YouTube channel.

Google data accessed

The application accesses the authorized YouTube channel identifier, channel profile information, upload playlist, video metadata, processing status, privacy status, and permission to upload videos.

How data is used

Data is used only to confirm the correct channel, prevent duplicate uploads, upload owner-approved videos, declare paid promotion where required, and verify publication status.

Storage and security

The OAuth client credentials and refresh token are stored as encrypted GitHub Actions secrets in a private repository. Public video identifiers and operational receipts may be retained for duplicate prevention and audit. No passwords are collected.

Sharing and sale

Google user data is not sold, rented, shared with advertisers, transferred to unrelated third parties, or used to train AI models. Processing is limited to Google APIs and GitHub Actions infrastructure required to operate the tool.

Retention and deletion

Credentials are retained only while the owner uses the automation. The owner can revoke access at any time from Google Account permissions. Revoked credentials and stored operational data are deleted when no longer required.
